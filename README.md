# ARTEM CARBON

Проект разворачивается целиком на одном VDS: публичный сайт, административная панель и API.

## Архитектура

- `https://artemcarbon.ru` — публичный сайт (статические HTML/CSS/JS, изображения, музыка и другие медиа).
- `https://artemcarbon.ru/admin/` — административная панель.
- `https://api.artemcarbon.ru` — публичный API и callback-адрес платёжного провайдера.
- PostgreSQL 16 — заказы, покупатели, оплаты и номера билетов.

GitHub используется только для исходного кода и резервного хранения. GitHub Pages не используется для хостинга.

## Развёртывание на VDS

Подготовьте PostgreSQL, пользователя приложения и `/opt/artems-carbon/server/.env` с DATABASE_URL, ADMIN_PASSWORD_HASH, SESSION_SECRET и остальными секретами. Не перезаписывайте существующий .env.

Затем выполните из репозитория:

```bash
sudo bash scripts/deploy-full-vds.sh
```

Скрипт обновляет checkout из `main`, копирует все публичные файлы сайта и медиа в `/opt/artems-carbon/site`, устанавливает админку в `/admin/`, разворачивает API и настраивает Nginx. Существующие данные PostgreSQL и секреты .env сохраняются.

## DNS

Укажите A-записи `artemcarbon.ru` и `api.artemcarbon.ru` на IPv4 нового VDS. Для `www` используйте CNAME на `artemcarbon.ru`.

После распространения DNS выпустите сертификаты:

```bash
sudo certbot --nginx -d artemcarbon.ru -d www.artemcarbon.ru -d api.artemcarbon.ru
```

## Безопасность и платежи

- Не храните секреты в Git.
- Не включайте платежи, пока не проверены настройки Т-Банка, фискализация и юридические документы.
- Не включайте отправку писем до проверки SMTP.
- Перед обновлением сохраняется резервная копия `.env`; база данных не пересоздаётся и миграции автоматически не запускаются.
