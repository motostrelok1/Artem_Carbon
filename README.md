# ARTEMS CARBON

Первый демонстрационный сайт мастерской Артёма Скарбана.

## Страницы
- `/` — главная, обучение, каталог продукции, демонстрационный заказ.
- `/admin/` — **отдельная демонстрационная панель** (общедоступна; без настоящих данных).
- `/legal.html` — заглушка юридических документов.

## GitHub Pages
Автоматическая публикация из `main`: `.github/workflows/pages.yml`.
Один раз выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес: https://motostrelok1.github.io/Artem_Carbon/

## Медиа
Загрузите предоставленные изображения с именами:
- `assets/hero-car.jpg` — автомобиль, широкий кадр;
- `assets/course-poster.jpg` — постер «Сделай сам»;
- `assets/product.jpg` — карбоновое изделие.

До загрузки фотографий отображаются стилизованные фоны и подписи.

## Безопасность
Это **публичный демопроект**. GitHub Pages не обеспечивает серверную аутентификацию и хранение секретов. Форма покупки не отправляет платежи, админка не изменяет бизнес-данные, номера не выдаются. Не вводите реальные данные покупателей или ключи эквайринга в исходники.

См. `docs/PROGRESS.md`.

## Фоновая музыка

Музыкальный плеер включён в `index.html`. Он использует аудиофайл `site-theme.mp3` в **корне репозитория**. Перед публикацией загрузите этот файл через GitHub → Add file → Upload files.

Браузеры обычно блокируют автозапуск со звуком без пользовательского действия. Сайт пытается запустить музыку при загрузке, затем при первом клике или касании; в шапке есть отдельная кнопка включения/выключения. Громкость по умолчанию — 32% от полной.

Публикуйте только аудио, на распространение которого есть необходимые права и лицензии.
